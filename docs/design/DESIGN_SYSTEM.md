# 设计系统

界面的颜色、圆角、阴影和字体都是 CSS 变量，值只写在两处：`web/app.css` 开头的 `:root` 和 `:root[data-theme="dark"]`（默认皮肤），以及 `web/skins.css`（其他皮肤）。改界面前先看这两处有哪些变量，组件规则里不写颜色字面值。

## 外观 = 皮肤 × 主题

- **皮肤只改设计，不改内容和功能**：皮肤只能改颜色、字体、字号、字重、行高、字距、间距、圆角、阴影和组件形态。任何皮肤看到的文字、按钮、链接和交互都必须和默认皮肤完全一样。不能用 `display: none`、`visibility`、`opacity: 0`、`content`、裁剪或按皮肤分支的 JS 让内容消失或改变行为。想让辅助文字不那么「灰」，只能用颜色层级、字重、字号这些设计手段。

- **主题**（浅色、深色、跟随系统）和**皮肤**（默认、Codex、Linear、Kami）互不相关，任意组合都要好看。
- `<html>` 上的 `data-theme` 总是 `light` 或 `dark`，跟随系统时也由脚本解析好再写上；`data-skin` 在默认皮肤时不设。两者在 `web/index.html` 的内联脚本里于首次绘制前设好，之后由 `applyLook`（`web/app.js`）维护，所以切换和刷新都没有闪烁。
- 选择按设备存在 localStorage（`collie.theme`、`collie.skin`），和其他偏好一样。
- 浏览器和 PWA 的状态栏颜色（`theme-color`）取当前的 `--bg`。

## 变量怎么用

| 变量 | 用途 |
| --- | --- |
| `--bg` / `--bg-2` / `--bg-3` | 主区、侧栏和次级面、悬停和按下 |
| `--line` / `--line-2` | 分隔线、较强的边框（输入框、按钮） |
| `--fg` / `--fg-2` / `--fg-3` | 正文、次要文字、弱化文字和图标 |
| `--accent` / `--on-accent` | 主按钮、开关、选中的选项 |
| `--attn` / `--attn-soft` / `--on-attn` | 需要人处理：待确认的会话、决策卡片、警告按钮 |
| `--ok` / `--danger` / `--pin` | 在线和成功、危险操作、置顶 |
| `--logo-bg` | 扩展标志下面的浅色底块，暗色主题也保持浅色（见「扩展图标」） |
| `--term-*` / `--code-*` / `--hl-*` | 终端、代码块、语法高亮 |
| `--shadow-sm` / `--shadow` / `--shadow-pop` / `--shadow-lg` | 选中块、卡片和输入框、浮动按钮、弹层 |
| `--scrim` / `--mark-mix` | 弹层背后的遮罩、搜索命中的底色深浅 |
| `--t-secondary` / `--t-meta` / `--t-desc` / `--t-empty` / `--t-hint` / `--t-icon` / `--t-group` / `--t-proj` | 文字的角色：标签和未选中的选项、标题下的电脑和目录等元信息、说明和空状态、占位符、安静的图标。组件写角色，不直接写 `--fg-2`、`--fg-3`，皮肤可以给某个角色换墨色。`--t-empty` 是空状态，`--t-group` / `--t-proj` 是侧栏的分区和项目标题 |
| `--fs-item` / `--fw-item` / `--fs-group` / `--fw-group` / `--tt-group` / `--fs-proj` / `--fs-card-h` / `--fw-card-h` | 侧栏会话名、分区标题（含是否全大写）、项目标题、卡片标题 |
| `--sans` / `--mono` / `--font-features` | 界面字体、等宽字体（终端也用它）、OpenType 特性。字体名可以写系统里可能有的专有字体，但不打包它的文件；开源字体放在 `web/fonts/`，带上许可证，只在用到的皮肤里下载 |
| `--fs-micro` … `--fs-title` | 字号阶梯：10、11、12、13（元信息、按钮、设置）、14（界面正文）、16、20。规则只用这些阶梯，需要时加减半像素 |
| `--fs-msg` / `--fs-msg-m` | 对话正文字号（桌面、手机）；偏好设置的「对话文字」在它上面加减 |
| `--fs-page` / `--fw-page` / `--fs-row-title` / `--fs-row-desc` | 页面标题栏的标题、设置行的标题和说明 |
| `--fw-normal` / `--fw-medium` / `--fw-strong` / `--fw-bold` | 字重：正文、强调和控件、标题、`<b>`（只在皮肤里生效） |
| `--lh-ui` / `--lh-msg` / `--lh-code` | 行高：界面、对话、代码。其他行高写成它们的加减 |
| `--ls-ui` / `--ls-title` / `--ls-caps` | 字距：正文、标题、全大写的小标签 |
| `--em-style` / `--bullet` / `--marker` | 对话里的强调样式、列表符号和它的颜色 |
| `--bw` / `--icon` / `--stroke` | 边框粗细、默认图标尺寸、图标线宽倍数 |
| `--btn-h` / `--btn-px` / `--btn-fs` / `--btn-fw` / `--btn-ls` | 按钮的高度、左右内边距、字号、字重、字距；分段选择器的字也用 `--btn-fs` |
| `--seg-h` / `--seg-px` / `--input-h` | 分段选择器的高度和选项内边距、输入框高度 |
| `--row-py` / `--row-px` / `--card-py` / `--card-px` / `--bubble-py` / `--bubble-px` | 侧栏行、卡片（标题和设置行）、消息气泡的内边距 |
| `--side-w` / `--col` | 侧栏宽度、对话列宽 |

| `--btn-radius` / `--seg-radius` | 按钮、分段选择器的圆角 |
| `--user-bg` / `--user-fg` / `--user-radius` | 自己发的消息气泡 |
| `--composer-line` / `--composer-focus` / `--composer-shadow` | 输入框的边框、聚焦边框和阴影 |
| `--sel-bg` / `--sel-ring` | 侧栏里打开着的那一项 |

## 选电脑

凡是让人选电脑的地方（派活、新建会话、设置里的电脑、扩展的运行在）都用同一个 `<select>` 选择器，列表和每一项都交给 `web/machines.js`：本 hub 在线的电脑加上当前选中的那台，按名字排，hub 有 agent 时排第一、没有时排最后；每项带在线圆点，下面一行写 `hub` 或系统、离线、默认。各处可选范围不同（新建会话还列出其他 hub 的电脑）用 `choices` 的参数表达，不要另写一份。

## 扩展图标

「接入」里每个扩展是一个圆角方块加图标，图标是清单 `icon` 指向的官方标志（`extensions/README.md` §2），由 `web/ext.js` 的 `extIcon` 用 `<img>` 原样显示，不重新着色，图片占方块的 82%。官方 app 图标通常自带底色和留白，按原样显示即可。方块的底色是 `--logo-bg`，亮色主题是白色，暗色主题是略暗的浅灰，这样品牌色在任何皮肤和主题下都看得清。方块也表示状态：没开时图标半透明、边框加深，需要处理时外面加一圈 `--attn`。没有图标的扩展显示名字的第一个字。

## 图标

界面里的线条图标统一用 Lucide（ISC 许可，`web/vendor/lucide-LICENSE.txt`），用到的那几个放在 `web/icons.js`，`collieIcons.svg(名字)` 取用；要新图标就从 lucide-static 包里抄对应文件的内层标记加进去，不另画。图标走页面的 `svg` 规则，线宽跟 `--stroke`，颜色用 `--t-icon`，尺寸跟旁边的字走（卡片标题 15px、行内 12–13px、方块里 18px），样式在 `web/icons.css`。

- 卡片标题、设置分区标题前放一个图标；通向别处的行（唤起与回复、扩展市场、会话）用和扩展同款的方块装一个图标。
- 扩展自己的东西（收件箱会话、筛选、事件来源）用它的标志小图（`.src-logo`，底色同样是 `--logo-bg`），没读到扩展列表时只写名字。
- 空状态在文字上方放一个淡的图标，说明这里本该有什么。

## 加一个皮肤

1. 在 `web/skins.css` 加三块：`:root[data-skin="名字"]` 放和明暗无关的值（`--round`、字体、组件形状），`[data-theme="light"]` 和 `[data-theme="dark"]` 两块各放一整套颜色。颜色只写在明暗块里，否则会漏到另一个主题。
2. 加一个 `.skin-swatch.名字`，在 `web/app.js` 的 `skins` 列表里登记。
3. 对比度：`--fg-2` 在 `--bg` 和 `--bg-2` 上至少 4.5:1，`--fg-3` 至少 3:1，`--on-accent` 在 `--accent` 上至少 4.5:1，语法色在 `--code-bg` 上至少 4:1。
4. 用演示站（`sh scripts/demo.sh`）把每个皮肤的浅色、深色在桌面和手机宽度下都看一遍：侧栏、对话、决策卡片、屏幕、自动化、设备、偏好设置。

## 皮肤的取向

- **默认**：中性灰白，黑白强调色。
- **Codex**：安静的冷灰，主按钮是墨色胶囊，输入框浮在页面上，自己的消息是浅灰气泡，彩色只留给状态。排版是 12、13、14 三级，正文字重 430，对话行高 1.625，侧栏行距更紧。文字只分三级墨色：标题和正文用全墨，说明、标签、未选中的选项用 secondary（65%），时间、分区标题和安静的图标才用 tertiary。
- **Linear**：冷调石墨加一个靛紫强调色，圆角小、信息密。字体是自托管的 Inter（拉丁子集，约 68KB），开 `cv01`、`ss03`。
- **Kami**：暖纸色加墨蓝，对比柔和，适合长时间读对话。全部用衬线体（中文宋体系），只用 400 和 500 两种字重，不用斜体，列表符号是墨蓝的短横。

为什么选 Linear 和 Kami 见 `DECISIONS.md`。
