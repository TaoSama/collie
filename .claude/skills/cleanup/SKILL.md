# 清理

清理是删数据，删错了很难找回。每种对象不管多简单，都按下面四步走。

## 对象类型

| 对象 | 做法 |
| --- | --- |
| Antigravity（agy）会话：正常会话和空壳会话 | `references/agy-sessions.md` |
| 临时测试会话、herdr 窗格和测试目录 | `references/test-sessions.md` |

要清的对象不在表里，就不要套用别的类型的做法，先报告要清什么、打算怎么清。以后新增一种对象，在 `references/` 下加一个文件，再在这张表里加一行。

## 1. 盘点

- 弄清要清的是哪些对象（ID、名字、在哪台电脑上），按对象类型打开对应的 reference。
- 照 reference 把这个对象的痕迹都查出来：哪些文件、数据库里的哪些行、缓存里的哪些 key。只查，不改。

## 2. 备份并列清单

- 把所有要改动的文件拷到 `mktemp -d` 建的临时目录，记下目录路径。
- 把「要删的清单」报告出来：每个对象删哪些文件、哪些行、哪些 key。清单确认了再动手，多个对象一起清时逐个列。

## 3. 执行

- 严格按 reference 的步骤删。有应用自带的删除入口时优先用它，手删只补它清不掉的部分。
- 只删清单里的东西。执行中发现清单外的痕迹，先补进清单再删。

## 4. 核对无残留

- 再跑一遍第 1 步的盘点，应当什么都查不到；对象原来出现过的地方（应用的列表、Collie 页面）也都不再显示。
- 核对通过后删掉备份目录；不通过就用备份还原，查清原因再来。

报告写：清了哪些对象，每个删了哪些文件、行和 key，以及核对结果。
